# 195：连续源切点、先行显示与 mld / rep 样式

本轮只更新本地开发版，公开版本仍为 **0.25**，WCSNDM **0.0803**。未上传 GitHub，未修改 `r` 配布。

## 三层权威，不混用坐标

1. **乐谱时间**：UST／USTX 音符起点是实际音符／P 的目标位置；已知先行是它之前的支持段，不再把先行再加到起点之后。未绑定素材也显示紫色实际部分及已知的黄色先行。快速双击仍对齐这个 P，不以 UST 文件路径冒充物理音频。
2. **源时间与拉伸**：完整登记行、源 P、受保护辅音和 `sourceTimeMap` 共同决定伸缩。连续关系必须有确切物理源、audioId、regionId、实际后继和一致时钟。登记的后一行开始处是切割边界，不能替换成后一行的 P，也不能靠滑音连接推断同源。
3. **显示投影**：`NativeMaterialContinuity.h` 从真实放置结构导出切点和显示支持区；视图展开前缓存。波形按各自行支持及实际切点分配，不再用乐谱矩形裁掉前置先行或把它画到前一音里。切割线中间留口，乐谱音符本身不会因此缩短。

控制案例：源切点 **0.6 秒**，后一行源 P **0.75 秒**，两个乐谱音符为 **0.3–1.3 秒**、**1.3–2.2 秒**。共同时钟把源 P 映射到 **1.3 秒**，把真实切点映射到 **1.15 秒**——在第一个乐谱音符内部，而不是 1.3 秒处。音频边缘所有权和显示使用同一投影。

移动连续源组时，只对目标时钟作变换，保留原完整源支持和源分段；临时编辑时钟不能把先行重新裁回乐谱矩形。移动后的切点随当前时钟重新计算。

## 外观与选择

设置 → 界面 → **音符样式**：

- **mld**：较大的独立同色系波形包络，轻量圆角范围线。
- **rep**：矩形音符与内部紧凑波形。

持久键为 `ui.noteStyle`，默认／非法值回到 `mld`。二者的音频和工程数据没有另一套实现。

统一颜色以 P 而不是 C 区分：先行 **#F4C000**，实际部分 **#7F69CA**。在素材管理器中登记为“衔接音”的完整发音整体绿色 **#32936F**、无先行；不能把内部 C/V 过渡分段误当作整个衔接音。登记编辑器、时钟 getter/setter 和新素材替换都使用同一无先行语义。

波形改为与界面协调的同色系包络和细高光，移除原红／橙／奶油多带渐变；保留源波形、实际渲染峰值、缩放和完整峰值采样功能。该调整是视觉设计选择，不是对任何第三方设计知识产权作法律判断。

未选音符始终保留导入后的暗基色，不因为选择其他音符而再被压暗；被选音符只在该基色上增加亮度。单选、多选、取消选择、组移动后的绘制均检查。可见先行段的命中区也属于相应音符，避免看见黄色却选到另一音。

## 针对性验证

`--smoke-native-material-appearance out` 使用已知 220 Hz 控制 WAV 和明确测试声学事实，只检查模型／时钟、源边界、视图与设置；不是 NN、ASR 或真人音质验收。

最终检查包括：

- 切点 1.15 秒与音频边缘／模型／展开后视图相同；不同变体不能产生伪同源切点。
- UST 实际起点即 P，双击对齐不再算成 P＋先行。
- 衔接音 getter/setter、源时钟和整块绿色显示没有先行。
- 深／浅主题 × mld／rep 的实际软件绘制截图，选中自身变亮、其他不变，取消恢复暗基色。
- 连续组移动后切点正确跟随，完整先行支持不被裁掉；点击黄色先行选择其所属音符。
- 真实设置控件的选项、默认、保存与应用。
