# 0.2.3 更新记录

对外版本固定为 **0.2.3**。以下小编号仅用于文档内部区分更新，不代表新的发行版本。只有用户明确要求时才提升对外版本号。

## 053 · 同轨道区域正常显示（2026-10-01）

- 区域右键增加“开始正常显示 / 关闭正常显示”。开启后，编辑同轨道其他区域时，该区域的音符、音高线、波形和参数完整显示并可编辑，可同时开启多个区域。
- 点击额外显示的音符保留当前区域；全选、框选和编辑包含已开启区域，关闭后清理其不可见音符选择。在额外区域范围内绘制新音符归属该区域，重叠时优先当前区域。
- 正常显示限同轨道，源文件编辑保持单区域；与半透明提示独立，正常显示时不重复叠加提示。开关随工程保存，支持撤销重做、复制、拆分和合并，公开版本保持 0.2.3。

## 052 · 区域音符提示显示（2026-10-01）

- 音符区域右键菜单增加“开始提示显示 / 关闭提示显示”，每个区域独立开关；编辑其他区域或其他轨道时，开启提示的区域按其轨道颜色显示半透明音符色块。
- 色块跟随音符的工程时间、音高、长度、区域移动和视图缩放，仅用于参考，不参与选中、拖动、删除或参数编辑。当前编辑区域正常显示，源文件编辑中不叠加提示。
- 开关随工程保存，支持撤销重做；拆分及复制继承状态，合并时任一区域已开启则保留开启。提示不改变声音或渲染缓存，公开版本仍为 0.2.3。

## 051 · 音符区域拆分吸附到间隙（2026-10-01）

- 音符轨的“拆分”自动选择离点击位置最近、不会穿过音符的间隙。点击间隙时保持原位置，首尾相接的音符可在公共边界拆分，距离相同时优先前方边界。
- 重叠音符作为一个连续组处理，避免切断长音；只有一个音符或没有安全间隙时禁用拆分。音符 ID、长度、绝对时间、音高曲线及 FLAG/DS 参数完整保留，左右区域只重新划分归属。
- 伴奏、纯音频和空白区域仍按点击位置拆分；区域边缘裁剪保持原有行为。支持一次撤销、重做及工程保存重开，公开版本仍为 0.2.3。

## 050 · 调音界面按区域独立显示（2026-10-01）

- 点击上方轨道中的区域后，下方调音界面只显示该区域的音符、音高线、参考线、波形及参数线；拆分后的左右区域分别显示，合并区域仍显示自身全部内容。
- 切换区域清理不可见音符的选中状态，全选、框选、参数编辑和歌词键盘导航跟随当前区域，避免误改同轨道的其他区域。切换只改变编辑视图，不改动工程音符、曲线或播放内容。
- 保持原工程时间位置，兼容普通调音、各 UTAU 模式、DiffSinger 和源文件编辑；公开版本仍为 0.2.3。

## 049 · 添加空调音片段（2026-09-30）

- 上方轨道空白处的右键菜单新增“添加空调音片段（10 秒）”，从右键位置开始创建无音频、无音符的调音区域，并自动选中，便于继续绘制音符。
- 只允许非伴奏轨道使用；伴奏轨道禁用该项，轨道以外或已有区域内部不提供创建入口。非伴奏轨道尚未开启音符编辑时同步开启，保留原引擎、音源及 FLAG 设置。
- 创建与开启音符编辑合并为一次撤销，支持重做及工程保存重开；菜单记录右键时的轨道和时间，不跟随菜单打开后的鼠标位置变化。公开版本仍为 0.2.3。

## 048 · 区域独立响度包络（2026-09-30）

- 响度包络改为每个区域独立保存，以区域起点为相对时间；只在区域内部绘制，空白处不再显示整轨横线。移动、复制或多选移动区域时，控制点与区域一起移动。
- 拆分自动保留左右两段的响度变化和分界值，之后各自编辑；裁剪不拉伸包络，保留部分仍对齐原音频。合并保留各来源包络与增益，再为合并区域提供独立的 0 dB 包络，避免合并导致声音变化。
- 旧版整轨包络在加载时自动转换到各区域，保留原工程时间对应的响度；重新保存后使用区域包络格式。播放、导出、保存重开和撤销重做同步生效，公开版本保持 0.2.3。

## 047 · 整轨响度包络（2026-09-30）

- 上方每条轨道内容区中央增加默认 0 dB 的响度包络横线，跨同轨所有片段连续生效。双击线添加点，拖动点调整时间 / 响度，点间直线连接；Shift 精调响度，Esc 取消拖动，Delete 删除选中点，右键点可删除、恢复 0 dB 或重置整轨包络。
- 范围为 -60 至 +12 dB，底部为静音；居中为 0 dB，上下半区分别显示增强和衰减，音量随绘制的直线连续变化。第一个点自动补上起止 0 dB 锚点；末端之外保持最近点的值。
- 包络按工程绝对时间控制整轨输出，与轨道音量、片段旋钮及淡入淡出叠加，适用于伴奏、普通音频、UTAU 和 DS。播放、混音导出和分轨导出共用同一处理，不改变音高 / FLAG 推理结果，也不重新生成合成缓存。
- 包络随工程保存和重开；每次拖动松开后一次性应用，支持撤销重做。移动、裁剪、拆分和合并片段不移动整轨包络。对外版本仍为 0.2.3。

## 046 · 响度控件随轨道缩放（2026-09-30）

- 左下角音量图标和旋钮按轨道高度连续缩放，默认比原来更小；横向空间不足时先收缩图形、隐藏音量图标，优先保留可读的 dB 数字。
- 数字保留清晰字号，移除整块遮挡波形的底色，仅给数值保留小面积衬底；矮轨道将紧凑控件放在标题行，避开静音按钮和标题文字。对外版本仍为 0.2.3。

## 045 · 片段响度控件样式（2026-09-30）

- 片段左下角改为“灰色递增音量图标 + 灰色圆形旋钮 + 蓝色有符号数值 + 灰色 dB 单位”的横向样式；0 dB 显示为“+0 dB”，指针朝上。
- 图标、旋钮及读数共同作为响度拖动区域，保留上下拖动、Shift 精调、双击复位和 Esc 取消。窄片段 / 矮轨道使用紧凑布局，对外版本仍为 0.2.3。

## 044 · 轨道区音符预览（2026-09-30）

- 上方音符轨的片段内显示迷你音符条，按工程中的实际起点、时长和音高绘制；不依赖源音频或合成缓存，适用于 MIDI、普通 UTAU、DS 及其他音符调音轨。
- 音符轨采用统一的音高比例，便于对照主唱和和声；有源音频时淡化底层波形。伴奏 / 原音轨仍显示原有波形，静音区域的音符相应变暗。
- 编辑音符、移动片段、裁剪、拆分、合并和保存重开后预览同步更新；拖动裁剪边界不拉伸内部音符，外扩部分保留空白。原有旋钮及片段操作保留，对外版本仍为 0.2.3。

## 043 · 片段响度旋钮（2026-09-30）

- 上方轨道区每个片段左下角增加响度旋钮及 dB 读数：上下拖动调节，按住 Shift 精细调节，双击旋钮恢复 0 dB。范围从静音到 +12 dB，松开鼠标应用；Esc 取消本次拖动。
- 只调节操作的片段；合并区域的旋钮统一调节其中所有来源，保留来源间原有响度比例。播放及导出生效，增益随工程保存，每次拖动支持一次撤销 / 重做。
- 旋钮与移动、裁剪、淡入淡出和框选分别命中；低轨道高度时使用紧凑旋钮，极短片段可放大时间轴后调节。对外版本仍为 0.2.3。

## 042 · 同轨片段合并（2026-09-30）

- 片段右键菜单新增“合并”：选中同轨道的两个或更多片段后可合为一个区域；跨轨道、只有一个片段或选区失效时禁用。“拆分轨道”改名为“拆分”。
- 合并保留各来源的时间位置、空白、重叠、增益、静音、淡入淡出和音符 / FLAG 数据，不写入烘焙音频；支持撤销重做、保存重开、整体移动、裁剪与再次拆分。
- 对外版本保持 0.2.3，合并后的内部来源信息随工程保存。
- 拆分后只含一个来源的片段恢复为普通片段。HAMOOD 的单音频分析接口要求先拆分多来源合并区域，避免误将第一个音源当成整个区域分析。

## 041 · 轨道区框选与多片段操作（2026-09-30）

- 在上方轨道区空白处按住左键拖动可框选，支持同轨多个片段和跨轨道选择；片段和对应轨道栏同步高亮。Shift 框选 / 点击追加，Ctrl 点击切换选中，Alt 拖动可从片段内部开始框选。
- 框选后拖动任一选中片段的中间，可整体平移并保留相对间距；到达工程起点时整体停止。拖动两端仍只裁剪当前片段，右键仍可拆分当前片段。
- 上方轨道区获得焦点时 Ctrl+A 全选片段，Delete 删除所选片段，Esc 取消框选或清空选择；整体移动和批量删除均支持一次撤销，避免误删下方旧选中的音符。版本保持 0.2.3。

## 040 · 片段两端裁剪与空白扩展（2026-09-30）

- 上方片段两端增加竖向边界拖柄并扩大命中范围：拖中间移动整段，拖两端只改变片段边界，内部内容不再按比例伸缩。
- 向内裁掉范围外的内容，向外增加空白；左右扩展均保持原音频和音符的绝对时间。音频内容范围独立保存，波形、播放及导出识别空白，裁掉后再拉长不会重新引入隐藏音频。
- 边界操作支持一次撤销 / 重做和工程保存重开；兼容之前的右键拆分。MCP 的 `resize_clip` 仍保留原本明确的整体时间伸缩语义，对外版本保持 0.2.3。

## 039 · 音频片段右键拆分（2026-09-29）

- 上方音轨内的片段新增右键菜单“拆分轨道”，在右键点击的时间位置分为左右两段，仍位于同一轨道；不移动后续片段，可一次撤销 / 重做。
- 保留源音频位置、播放比例、片段增益及静音状态，右半段接着原位置播放；音符按位置分配，跨越切点的音符沿用音符拆分逻辑。切点过近边缘时禁用，避免极短片段。
- 伴奏及原音播放的连续切口不再叠加额外防爆音淡化，避免接缝处出现短暂音量凹陷；统一播放边界的采样取整，避免切口重复播放一个采样。工程保存后保留拆分结果，对外版本继续 0.2.3。

## 036 · HAMOOD 伴奏分析与 MCP 和弦参考（2026-09-29）

- 当前窗口 MCP 新增 `hamood_analyse_audio`、`hamood_audio_context` 和 `hamood_alignment_preview`：后台调用 Beat This! small0 / BTC 170 类模型，读取带工程时间的和弦、拍点、小节首拍与低频音级候选；按选区 / 时间范围分页读取。
- 分析结果保存到工程旁 `.hjpx.hamood-cache`，音频移动后按当前片段位置重新映射时间，源音频变化后拒绝旧缓存。模型分析使用与编辑器相同的解码时间基准，避免 MP3 解码延迟差异；不修改音频、曲速或音符，局部拍点对齐只给出预览。
- `hamood_preview` / `hamood_generate` 新增 `audio_clip_id`：在原调内音程附近参考和弦成员，并以乐句内声部连接代价选择音高；低分、未知和弦或未覆盖的音符保留原规则。延续 UTAU / DS FLAG 与唱法继承，一次生成可撤销。
- 本机复用已有 Python / PyTorch 环境，新增两个模型权重合计约 20 MB。此分析扩展需要配置运行时，不把完整 PyTorch 打入原配布包。模型分数不是准确率，低频特征不是分离后的贝斯谱。
- 对外版本继续 0.2.3，WCSNDM 继续 0.0803。用法与当前边界见 `docs/hamood-audio.md`。

## 035 · 独立伴奏轨道（2026-09-29）

- “轨道”菜单与轨道区域空白处右键新增“新建伴奏轨道”。选中后使用“导入音频”或将音频拖到该轨道；多选导入的文件按顺序排列。
- 伴奏直接读取原始音频，不分析音高、不读取音频旁的调音标记，也不进入 DS、UTAU、WORLD、LLSM 或 HiFiGAN 合成。变调、拉伸与音符编辑禁用；裁剪片段长度不改变原音高或播放速度。
- 伴奏参与正常播放、混音与 WAV 导出，保留音量、声像、静音和独奏；不会像素材轨道一样只在选中时发声。高级气声 / 非气声分量导出对伴奏不可用。
- 支持工程保存重开、撤销 / 重做，并通过 MCP 的 `add_track(accompaniment=true)` 创建。对外版本继续 0.2.3；说明见 `docs/accompaniment.md`。

## 034 · WAV 高级气声 / 非气声分量导出（2026-09-29）

- 每次导出的 WAV 设置窗口新增可展开“高级”，包含互斥的“仅导出气声”和“仅导出非气声”；均不选则导出完整声音，仅对本次生效。
- 接通原生 LLSM、WORLD 的真实合成分量，以及 WCSNDM 0.0803 纯 K2 的 Mx2 / Mx1。DS、HiFiGAN、原始音频及无法可靠分离的引擎 / 内核显示禁用原因。
- 按单轨 / 全部轨道 / 上次渲染范围及实际内核判断可用性。独立缓存、保留项目 FLAG，导出后恢复完整试听；不支持或合成失败时停止，避免导出完整混音冒充分量。
- 公开版本保持 0.2.3，WCSNDM 保持 0.0803。使用范围与分量含义见 `docs/audio-export.md`。

## 033 · 每次导出先确认 WAV 格式（2026-09-29）

- 移除导出菜单中的独立“WAV 格式设置”项。选择单个轨道或全部轨道后，立即弹出声道、采样率和位深设置；点击“下一步：保存位置…”后再选文件位置。
- 每次导出都显示设置窗口，上次参数只作为默认值。“导出上次渲染音频”使用相同顺序；取消格式窗口不会进入文件选择或渲染。
- 全部轨道继续每轨一个文件并使用本次统一参数，原有采样率转换、声道混合与位深逻辑保持。对外版本继续 0.2.3。

## 032 · HAMOOD 手动小节分段与调性分析修正（2026-09-29）

- 手动调性新增分段表：选择上方调性，填写起始小节和小节数量，添加、更新或删除区间。结束小节包含在范围内，添加后自动接续下一小节；未添加分段时兼容原来的单一手动调性。
- 区间按工程拍号、拍点原点与曲速映射计算；重叠、倒序、无效调性和未覆盖的目标音符会阻止生成并说明原因。跨边界长音按起点所在段移调，原时长保持。
- 自动分析改为按拍长统计音级，与标准大小调轮廓做相关性比较。整轨上下文、邻近段与调性连续性共同处理短句和稀疏段；充分局部证据限制平滑，避免抹去持续的大小调变化。
- 选区仅限制生成音符，自动分析始终使用同一源轨上下文。预览显示小节范围、前三个候选和歧义提示；检测到持续的多调性区域时提示单一调性只代表整体匹配。
- 当前窗口 MCP 同步支持 `manual_sections`。对外版本保持 0.2.3，WCSNDM 保持 0.0803。

- 每次成功生成 DS pitch 时，独立保存该次写入的预测曲线，并以浅蓝色虚线显示；当前可编辑音高仍为实线。手动拉点、自由绘制、画直线、拉平音高不会覆盖参考线，参考线也不能被选中或拖动。
