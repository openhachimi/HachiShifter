# 局部曲速的音符处理选项（0.2.2）

在时间标尺上右键，选择“改变曲速…”。输入 BPM 后，可以在“音符处理”中选择：

- **同步修改音符**：默认选项，保持之前的行为。按新的曲速重新计算合成轨道片段、音符和曲线的时间，音符随拍位移动和伸缩。
- **不修改音符**：只修改曲速图。现有音符的绝对时间位置、长度、音高控制点、包络，以及片段和原生连接数据保持不变；小节/节拍网格按新的曲速显示。

该选项针对这一次局部曲速操作，每次打开对话框默认“同步修改音符”。两种方式都可撤销/重做，并随工程正常保存。取消或输入超出 20–400 的 BPM 不会修改工程。

开发验证入口：`HachiShifter Next.exe --smoke-tempo-change [dialog-screenshot.png]`。
覆盖插入/修改曲速点、提速/降速、起始曲速、已有多个曲速点、跨曲速点音符、控制曲线、参考录音不伸缩、撤销/重做、保存/读取，以及实际对话框的两个选项、取消和无效输入。
