# OTO 高级包络（0.2.4 / 内部更新 066）

选中要处理的音符，点击包络预设旁的 **高级包络**，或右键 **响度包络**，打开 **OTO 尾段淡出** 设置窗口。窗口先编辑草稿；**应用** 保存但保留窗口，**应用并试听** 保存后从选区起点试听。关闭窗口丢弃尚未应用的修改，已经应用的修改可在主窗口撤销。

## 细节设置

- **启用尾段淡出**：关闭后恢复原包络效果，保留这些细节以便重新启用。
- **曲线形状**：线性按振幅降低；平滑 S 曲线在两端更柔和。
- **淡出起点 / 终点 · 尾段 %**：在 OTO 最后一段内部指定范围，默认 0% 至 100%。拖动预览上方的两个圆点也可调整。起点须早于终点，边界跟随音符时长和 OTO 分区。
- **淡出前响度 · %**：相对原包络的振幅倍率，默认 100%。例如 80% 约为 -1.94 dB；它作用于整段淡出前的发声，而不只作用于尾段。
- **结束响度 · %**：到达终点后保留的倍率，默认 0%（静音）；不能大于淡出前响度。这个倍率以淡出起点的原包络响度为基准；原包络后续收尾不再重复叠加。
- **曲线强度**：默认 1；小于 1 先快后慢，大于 1 先慢后快，范围 0.25–4，仅 S 曲线可调整，线性模式始终为直线。
- **恢复默认**：草稿恢复为启用、线性、完整尾段、100% 至 0%、强度 1；点击应用后才写入工程。

预览可切换当前选中的可用音符，实线为原包络，绿色虚线为替换收尾后的实际响度。背景标出 OTO 尾段和淡出范围，下面给出相对音符起点的毫秒位置。多选时应用会统一所有可用音符的参数；窗口显示可用数量及是否原先存在不同设置。没有有效 OTO 尾段的音符跳过。工程在窗口打开期间发生其他修改时，应用会提示重新打开以更新预览，避免覆盖新修改。

## OTO 与原包络

普通 UTAU 使用固定辅音 / 拉伸元音的两段 OTO；界·UTAU / 谋·UTAU 使用实际 2、3、4 段 OTO，取最后一个存在的分区。单音 OTO、辅音速度、预发声、音符长度及手动分界都会影响尾段位置。没有长度的末段不产生额外淡出。DS 没有 OTO 分区，不启用此功能。

淡出起点之前保留原包络形状，并应用“淡出前响度”倍率。从起点开始固定原包络的基准响度，再用所选直线或 S 曲线连续降到结束响度，避免原包络收尾和淡出相乘后出现折弯。若淡出起点本身静音，整个淡出仍为静音。响度包络通道的实线及标点仍编辑原包络；绿色虚线、音符形状和波形显示叠加后的结果。自动采样只用于绘图，不写入密集标点。试听和 WAV 导出共用混音规则，修改效果继续复用原始合成缓存。

模式与细节按音符保存，支持多选一次撤销、重做、复制、HAMOOD 和声和工程重开。旧工程缺失细节时，沿用原来的完整尾段淡出默认值；关闭效果不会删除原包络或 FLAG。

## MCP

`set_note` 的 `tail_fade` 支持 `off`、`linear`、`smooth`；另有五个可选数值字段：`tail_fade_start_percent`、`tail_fade_end_percent`、`tail_fade_start_gain_percent`、`tail_fade_end_gain_percent`、`tail_fade_curve_power`。省略的字段保持当前值，参数范围与 GUI 相同。无效范围先拒绝整次编辑，不会改动同一请求中的其他字段。选区与工程快照返回这些设置；实时编辑须提供 `expected_revision`。批量音符可用 `editor_batch` 合并撤销。
